# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Resumen

- Trata a todo el mundo con respeto.
- No se toleran insultos, acoso, discriminación ni ataques personales.
- Las críticas técnicas se hacen sobre el código y los datos, no sobre las
  personas.
- Se aceptan correcciones con argumentos y fuentes.

## Aplicación

Los maintainers pueden editar o rechazar contribuciones que incumplan estas
reglas, y pueden bloquear temporal o permanentemente a quien las incumpla.

Para reportar un incidente, escribe a los maintainers de forma privada. Los
reportes se tratan con confidencialidad.

## Alcance

Se aplica a issues, pull requests, discusiones, chat y cualquier espacio del
proyecto.
